Overview

JamulusAccess lets you play music live over the Internet with other musicians, as in a rehearsal room, on your own with your screen reader (NVDA, JAWS, Narrator), using the keyboard only. It is Jamulus, the reference free software for online music, with every screen reworked for screen readers:

  • the mixer becomes a list: one row per musician, with their volume, pan, mute, solo, group, level and profile;
  • the server list is read item by item, with the ping rated good, fair or too high;
  • the chat messages are a list you can read again with the arrow keys;
  • musicians joining and leaving, the connection and the recording are announced;
  • every control has its explanation on Shift+F1;
  • the Peak Watcher announces the peaks of your input, so you can set your level without seeing it;
  • the value you read stays on your braille display.

At any time, Ctrl+Shift+H shows the list of all shortcuts, F1 opens this manual and Ctrl+F1 the changelog.

Jamulus in a nutshell: each musician sends the sound of their instrument or voice to a server. The server mixes all the musicians and sends each one their own mix, set in their mixer. To be playable, the sound must make the round trip very quickly: the overall delay should stay below about 50 milliseconds. A server close to you, a wired connection rather than Wi-Fi and an ASIO sound card help a lot.

Installation and first start

The installer puts JamulusAccess in Program Files and creates a JamulusAccess folder in the Start menu with three shortcuts: JamulusAccess, JamulusAccess Server and JamulusAccess Manual. A desktop icon is offered, unchecked.

JamulusAccess keeps its own settings, in the JamulusAccess folder of your application data (AppData). On the first start, if Jamulus is already installed, it takes a copy of its settings: your profile, your servers and your sound card are carried over. Jamulus is not changed and keeps working as before. Both programs can stay installed together.

The program follows the Windows language, or the Jamulus one if its settings were carried over. To change it: Ctrl+P (my profile), Language list, then restart JamulusAccess.

Before playing, set up your profile with Ctrl+P: your name (the one the other musicians see), your instrument, your city, your country and your skill level.

The sound card

On Windows, Jamulus works with an ASIO driver: your sound card's own if it has one, otherwise a universal driver such as ASIO4ALL. Choose it in Ctrl+S, Audio Device list.

This list does not switch cards while you move through it with the arrow keys: switching resets the card and cuts the sound, including your screen reader's if it uses the same card. Press Alt+Down Arrow to open the list, choose with the arrow keys, then Enter: only then does the card change.

JamulusAccess respects your card's settings, like music software (a DAW):

  • at start, it takes the buffer size set in the card, without changing it;
  • it changes the sample rate only if it differs from the one Jamulus needs (48,000 Hz);
  • when you choose another value in Buffer Delay (Ctrl+S), JamulusAccess asks the card for it; the value shown is always the one the card really uses.
Why: the original Jamulus imposed its own buffer size and tried several at start. The whole card was reconfigured, and the voice of a screen reader on the same card became choppy. In JamulusAccess, your card is reconfigured only when you ask for it.

The main window

JamulusAccess fits in a single window, with two views:

  • Ctrl+1: the session, that is the mixer and the settings of your sound (Connect button, Mute Myself, reverb…);
  • Ctrl+2: the chat messages, on the line to write. Escape goes back to the session.

In the session, Tab moves from one control to the next. Alt+M mutes or unmutes your own sound for the others (Mute Myself). Sliders (reverb, and in the settings the input balance) are set with Alt+Up Arrow and Alt+Down Arrow, Alt+Shift for a small step.

Announced without you doing anything: connecting and disconnecting, a musician joining or leaving, a musician who muted you, the start and end of a recording on the server, and each new message.

To quit: Ctrl+Q or Alt+F4. If you are connected, JamulusAccess first asks "Disconnect and quit?", with No as the default, so you never leave a session by mistake.

Connecting to a server

Ctrl+C opens the connection window. The focus goes to the first server of the list as soon as it is filled.

  • Directory: the drop-down list chooses the directory, that is the music genre (Any Genre 1, 2 and 3, Rock, Jazz, Classical…) or a custom directory.
  • Filter: type part of a name to keep only the servers that contain it; "#" keeps only the servers where musicians are already playing.
  • Servers: each row is a server. Up Arrow and Down Arrow move between servers, Home and End go to the first and the last.
  • Right Arrow and Left Arrow read the server's information one by one: name, ping (with its rating: good, fair or too high), number of musicians, location, version, permanent server or not, address. Going back to the very start with Left Arrow reads the whole row again. Then Up Arrow and Down Arrow keep the same item: handy to compare the ping of all servers.
  • The musicians already there are under their server; with Show All Musicians checked, they are listed and read the same way: name, instrument, city, country, skill level.
  • Enter on a server connects to it. The Connect button also works with Enter.
  • Server Address: for a private server that is in no directory, type its address (for example myserver.example.com:22124), then Connect.

Some servers ask you to accept their conditions. The Server conditions box then shows the text of the conditions, to read with the arrow keys, then the "I have read the conditions and agree" check box, and the Accept and Decline buttons.

To disconnect: the Disconnect button of the session (Ctrl+1, then Tab).

The mixer

The mixer is a list: one row per connected musician, you included. It sets what you hear: turning someone down in your mixer changes nothing for the others.

  • Up Arrow and Down Arrow: the musicians.
  • Left Arrow and Right Arrow: the musician's parameters, in this order: Volume, Pan, Mute, Solo, Group, Level, Profile (Pan only in stereo, with a server that supports it). When you move to another musician, you stay on the same parameter.
  • Alt+Up Arrow and Alt+Down Arrow: change the value. Alt+Shift+Up Arrow and Alt+Shift+Down Arrow: small step.
  • Enter or Space: switch Mute or Solo, or read the Level again.
  • M: mute the musician. S: listen to them alone (solo).
  • Level: the musician's current sound level; Enter reads it again.
  • Profile: their instrument, skill level, city and country.
  • A musician who muted you in their own mixer is reported.

Sorting the musicians: Ctrl+N by name, Ctrl+I by instrument, Ctrl+G by group, Ctrl+T by city, Ctrl+E by channel, Ctrl+O no sorting. The View menu also offers Own Fader First.

In the Edit menu: Ctrl+L sets all faders to the new client level, Ctrl+F auto-adjusts all faders; it also clears the stored solo and mute settings and the chat history. The File menu saves and loads the mixer setup.

Messages

Ctrl+2 opens the chat messages with the focus on the line to write: type your message, then Enter to send it to everyone. Shift+Tab goes to the list of messages. Each new message is announced, even while you are in the mixer; the view does not open by itself, so you are never taken out of what you are setting.

  • Up Arrow and Down Arrow read the messages. Each row gives the name, the text and the time; the announcement of a new message does not say the time.
  • Enter on a message with a link offers to open it in your browser (Yes or No). Ctrl+C copies the message.
  • Tab goes back to the line to write.
  • The server's welcome message comes first, after "Welcome message:".
  • Escape or Ctrl+1: back to the session.

Status, ping and delay

  • Ctrl+Shift+G announces the connection status: the server, the number of musicians, the ping, the delay, audio dropouts, your input level, the upload rate, and whether you are muted or the server is recording.
  • 1 (the key at the top left of the keyboard, not in a text field): the ping, the round-trip time to the server.
  • 2: the overall delay, the lag you really hear, with its rating: good, fair or too high.

The overall delay includes the ping, the Jamulus buffers and your sound card's buffer. If it is too high: choose a closer server, use a wired connection, or lower the Buffer Delay in Ctrl+S.

The Peak Watcher

The Peak Watcher tells you when your input sound gets too loud, so you can set your microphone or instrument without seeing a meter.

  • Ctrl+W opens the Peak Watcher box: type the threshold in decibels (0 or below, for example -6), then OK. The threshold is saved and the watcher turns on. It speaks only during a session.
  • Ctrl+Shift+W turns the watcher on or off.
  • While it is on, each peak of your input above the threshold is said, for example "-3.2". At most four values a second, the loudest of the moment; each value cuts the previous one, so you always hear the latest.
  • What is measured: your input after the input boost, before the reverb.
  • The watcher is always off when JamulusAccess starts.

Settings

  • Ctrl+S: audio and network settings: audio device, input and output channels, Buffer Delay, jitter buffer, audio channels (mono, stereo), audio quality.
  • Ctrl+D: advanced settings: custom directories, new client level, input boost and more.
  • Ctrl+M: MIDI control settings, to drive the mixer with a control surface.
  • Ctrl+P: my profile: name, instrument, city, country, skill level, and also the program language and the audio alerts.

In these windows, Ctrl+Tab changes tab, Tab moves between settings and Shift+F1 explains the setting that has the focus. Escape closes the window. On a check box, Enter checks or unchecks it, like Space.

Hosting a server

The JamulusAccess Server shortcut in the Start menu starts JamulusAccess in server mode, to host other musicians yourself. The server window is accessible like the rest: the list of connected musicians is read item by item with the Left and Right arrows, the directory registration status and the recording status can be read with the keyboard, and Shift+F1 explains each setting.

For musicians from other homes to join you, the server's UDP port (22124 by default) must be open in your modem or router.

Updates and help

At start, JamulusAccess checks whether a new version exists. If there is one, a window presents what's new, to read with the arrow keys, and offers Update or Later. Update downloads the installer, checks it, installs it and starts JamulusAccess again by itself; Windows only asks for permission to install. Your settings are kept.

To check at any time: Help menu, Check for Updates. The latest installer is also always at the same address:
https://github.com/reaperaccessible/JamulusAccess/releases/latest/download/JamulusAccessInstaller.exe

The Help menu holds this manual (F1), the changelog (Ctrl+F1), the update check, the control explanation (Shift+F1) and the About JamulusAccess window.

To report a problem: https://github.com/reaperaccessible/JamulusAccess/issues, or through the reaperaccessible.fr website. Please do not report JamulusAccess problems to the Jamulus project.
